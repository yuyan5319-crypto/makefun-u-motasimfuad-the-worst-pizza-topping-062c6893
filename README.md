The Worst Pizza Topping: one original funny line pitching a terrible pizza topping — a "Dentist Special" whose gummy-bear topping bills your teeth instead of fixing them.

> Try our new 'Dentist Special' pizza: gummy bears baked into the cheese, so every bite yanks out a filling and installs a cavity — free toothache with every slice!

## Run it

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the line is not 1–200 characters or not a single line, so the gate can never see an invalid entry.
